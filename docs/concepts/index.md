# Concepts

These pages explain the contracts that must remain correct when a filter grows
beyond its pixel loop.

- [Filter lifecycle](filter-lifecycle.md): construction, metadata, dependency
  declaration, and frame generation.
- [Frames and ownership](frames-and-ownership.md): reference lifetimes,
  transfers, and typed access.
- [Scheduling and dependencies](scheduling.md): spatial, temporal, and
  multi-input frame requests.
